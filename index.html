02

Bolt the Bird

An AI that drafts Magic: The Gathering, learned to build winning decks from real games, and taught itself to play them.

Role
Solo ML Engineer
Timeline
Nov 2026 – present
Built with
Python, PyTorch, Rust, FastAPI
Story
The whole story
Code
GitHub

It learned to draft from 5.5 million real picks, then taught itself to build winning decks. A scoring model I built predicted they'd win 3.9 points more often. To check, I built a Magic game engine that plays every card in the set, and the prediction was wrong. Retrained on real game results, its decks now win 62% of games where human-style decks win 50%. Then I trained a game-playing AI with reinforcement learning and self-play: after about 790,000 games, it beats the strongest player I'd built into the engine 58% of the time.

  • Learned from 5.5 million real picks
  • A Magic rules engine in Rust that plays every card in the set
  • Reinforcement learning on real game results
  • Every version tested head to head, over 100,000 games
  • A game-playing AI trained with reinforcement learning and self-play
  • Online drafts and games on Nerd Leagues, now in testing
